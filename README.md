# JumpBot

Telegram-бот и HTTP API для оценки вертикального прыжка по видео со смартфона.

> Проект предназначен для тренировочной аналитики. Результаты не являются медицинским заключением или лабораторным измерением.

## Возможности

- приём видео через Telegram;
- очередь обработки Celery + Redis;
- извлечение позы RTMPose/COCO-17 с резервным MediaPipe;
- виртуальная следящая область удерживает выбранного спортсмена и снижает влияние фона;
- высота по времени полёта, сегментному центру масс и параболе полёта;
- время полёта, наклон корпуса, градусы/обороты и скорость сальтового вращения;
- скорость отталкивания, фазы прыжка и оценка качества;
- Free/Pro-квоты;
- история анализов через FastAPI;
- Telegram Mini App: безопасный вход через `initData`, загрузка, статус, история и сравнение;
- экспорт JSON/CSV;
- PostgreSQL, Docker Compose, Alembic и pytest.

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и укажите `TELEGRAM_BOT_TOKEN`.
2. Запустите инфраструктуру:

```bash
docker compose up --build
```

3. API будет доступно на `http://localhost:8000`, документация — на `/docs`.

Mini App раздаётся по адресу `/miniapp/`. В BotFather нужно указать публичный HTTPS-адрес
этого маршрута. Каждый запрос Mini App проверяет подпись и срок действия Telegram `initData`;
рост передаётся только для выбранного анализа и не записывается в профиль.

API привязан только к localhost. Все маршруты с пользовательскими данными требуют заголовок
`X-API-Key`, значение которого задаётся в `.env`. `/health` остаётся общедоступным для локальной
проверки состояния.

Для локальной разработки без Docker:

```bash
python -m venv .venv
pip install -e ".[dev,cv]"
pytest
uvicorn jumpbot.api.main:app --reload
```

## Съёмка

### Движок распознавания позы

По умолчанию анализ выполняется RTMPose через ONNX Runtime на CPU:

```env
POSE_BACKEND=rtmpose
POSE_TRACKING_ROI_ENABLED=true
```

Модели загружаются во время сборки Docker-образа, поэтому рабочему контейнеру
не требуется интернет. Для временного отката установите
`POSE_BACKEND=mediapipe` и пересоздайте контейнер worker.

- камера неподвижна и расположена сбоку;
- спортсмен целиком виден в кадре, включая стопы;
- перед прыжком нужно постоять неподвижно 1–2 секунды;
- предпочтительно 60 или 120 FPS;
- один человек в кадре, ровный видимый пол;
- приземление примерно в точке отрыва.

Вращение измеряется в плоскости бокового кадра (сальто). Точный твист вокруг продольной оси
тела нельзя восстановить из одного строго бокового 2D-видео; для него потребуется фронтальный
ракурс или синхронная вторая камера.

## Архитектура

```text
Telegram/Aiogram ─┐
                  ├─ FastAPI ─ PostgreSQL
                  └─ Redis/Celery ─ OpenCV/RTMPose ─ storage/
```

Основные каталоги:

```text
src/jumpbot/api       HTTP API
src/jumpbot/bot       Telegram handlers
src/jumpbot/cv        pose, фильтрация, фазы и метрики
src/jumpbot/db        SQLAlchemy-модели и сессии
src/jumpbot/services  квоты, файлы и экспорты
tests                 модульные тесты
```

## Ограничения MVP

- масштаб по росту является приближением и чувствителен к перспективе;
- сегментный центр масс остаётся антропометрическим приближением, а не лабораторным измерением;
- RTMPose COCO-17 не содержит пятки и носки, поэтому контакт с полом оценивается по лодыжкам;
- вращение относится только к видимому сальтовому вращению в плоскости кадра;
- автоматические кадры отрыва/приземления нужно валидировать на размеченном датасете;
- при плохом качестве бот отклоняет анализ вместо выдачи псевдоточного результата;
- исходные видео по умолчанию хранятся локально; production-развёртывание должно использовать S3 и lifecycle policy.

## Безопасность

Перед production-развёртыванием выполните [security checklist](docs/SECURITY_CHECKLIST.md).
Для переноса на другой VPS используйте [чек-лист миграции](docs/HOSTING_MIGRATION.md).
Не размещайте `.env`, видео, дампы БД и токены в GitHub. Если токен когда-либо находился в
документе, сообщении или скриншоте, его необходимо отозвать через BotFather и выпустить заново.
Сообщайте об уязвимостях по процедуре из [SECURITY.md](SECURITY.md), а не через публичные issue.
